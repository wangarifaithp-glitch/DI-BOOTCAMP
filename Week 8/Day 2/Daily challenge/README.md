# Week 8 Day 2: Country autocomplete

This is Daily Challenge 2, kept separate from the Day 1 travel-form challenge and the Day 2 React/Express challenge.

## Run the app

```sh
npm install
npm run dev
```

Type a country name to see case-insensitive matches, then select a suggestion to fill the input and close the list.

The country list is based on [Countries-JSBOOTCAMP-W9](https://github.com/devtlv/Countries-JSBOOTCAMP-W9/blob/90dc0d9f2702fbe055aa9587665b6b89ce82a95a/Countries.js).

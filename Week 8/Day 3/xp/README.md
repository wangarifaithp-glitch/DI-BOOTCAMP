y76u76# Week 7 Day 3 React XP

This Vite app contains two React hook exercises:

- A light/dark theme switcher using `useContext` and `useState`.
- A live character counter using `useRef` to read the text area and state to update the display.

Run `npm install`, then `npm run dev` to start the app. Run `npm run build` to create a production build.

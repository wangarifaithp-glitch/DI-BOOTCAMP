# Commonroom chat

## Start

```sh
npm install
npm start
```

Open `http://localhost:3000`. Set `PORT` to use a different port.

## Use

Choose a username and room to join. Use the channel list or the room field to switch rooms. Messages and active-user lists update live for everyone in the same room. The bell button requests optional browser desktop notifications; in-app notifications work without permission.

Messages are broadcast live and are not persisted. Room membership and active-user lists are held in memory and reset when the server stops.

# Page & Pine — Personal Book Library

A React + TypeScript book library built with Redux Toolkit. Add books, track read status, search and filter your collection, sort books, manage categories, and see reading statistics. Your library is saved in browser local storage.

## Run in Windows PowerShell

```powershell
npm.cmd install
npm.cmd run dev
```

Open the local URL shown by Vite. To create and verify a production build:

```powershell
npm.cmd run build
```

## Features

- Add books with a title, author, category, and notes.
- Mark books as read or unread; view reading statistics and progress.
- Search by title, author, or category.
- Filter by reading status and category; sort by date, title, or author.
- Remove books and delete categories.
- Save and restore the library with `localStorage`.
